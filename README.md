# Secret Code Generator

A beginner-friendly C programming project that generates random alphanumeric secret codes.

## Features
- Generates a 10-character code.
- Uses uppercase letters and numbers.
- Produces random codes.

## Language Used
C Programming

## Libraries Used
- stdio.h
- stdlib.h
- time.h

## How to Run
Compile using GCC:
gcc secret_code.c -o secret_code

Run:
./secret_code
